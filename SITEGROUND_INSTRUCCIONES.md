# Publicación de RIOH en SiteGround

El archivo `RIOH_SITEGROUND.zip` está preparado para extraerse directamente dentro de la carpeta `public_html` del dominio.

## Pasos

1. En SiteGround, abrir **Site Tools > Site > File Manager**.
2. Entrar a `public_html`.
3. Hacer una copia de seguridad de la versión actual.
4. Subir `RIOH_SITEGROUND.zip`.
5. Extraer el ZIP dentro de `public_html`.
6. Verificar que `index.html` y `.htaccess` hayan quedado directamente en `public_html`, no dentro de otra subcarpeta.
7. Comprobar la web pública y la ruta `/admin`.

El paquete no incluye archivos SQL, configuración de Vercel, Git ni archivos de desarrollo.
